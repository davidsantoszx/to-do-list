Aplicação de gerenciamento de tarefas desenvolvida com foco em organização, produtividade e desenvolvimento full stack.

Sobre o projeto

O projeto possui uma interface desenvolvida em React, com funcionalidades para organizar tarefas, acompanhar prazos e visualizar atividades em diferentes formatos.

A aplicação está em desenvolvimento e passará por uma nova etapa de implementação do backend utilizando Node.js.

Funcionalidades

Dashboard de tarefas

Organização por listas, prioridades e tags

Visualização de tarefas do dia e futuras

Calendário com visualizações diária, semanal e mensal

Mural de notas adesivas

Criação, edição e exclusão de tarefas
